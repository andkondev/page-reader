# Page Reader

The web page for Page Reader, a browser extension that reads web pages and PDFs aloud.

It is published at https://andkon.dev/page-reader/ through GitHub Pages (main branch, root folder). For now the page is the extension's privacy policy; a description of the extension's features will be added later.

`settings.css` and `free-voices.css` are copies of the extension's Options page styles, so the page looks like Options.
