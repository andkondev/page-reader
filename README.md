# Page Reader

The web page for Page Reader, a browser extension that reads web pages and PDFs aloud.

It is published at https://andkon.dev/page-reader/ through GitHub Pages (main branch, root folder). It holds the video tutorial (YouTube), a slideshow of the five Chrome Web Store screenshots (`screenshots/`), the Web Store link (not available yet), the warranty disclaimer and the privacy policy.

`settings.css` and `free-voices.css` are copies of the extension's Options page styles, so the page looks like Options.
